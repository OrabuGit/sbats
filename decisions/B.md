# Session B decisions

Small choices made without asking, one line each with the reason.

| Date | Decision | Reason |
| --- | --- | --- |
| 2026-11-14 | Site footprints are squares of 2 to 5 km centred on the analogs.json coordinates; the side per site is in `pipeline/sites.py` and in `data/sites.json` | A square maps directly onto the raster window; sizes follow the size of each feature |
| 2026-11-14 | Site terrain is reported twice: 463 m posts (`slope`, `roughness`) and about 31 m posts (`slopeFine`, `roughnessFine`) | Only the 463 m values are comparable with the targets and the grid; the fine values show the feature itself |
| 2026-11-14 | The 463 m window is a whole number of 463 m posts, so it is slightly smaller or larger than the stated footprint (written as `windowKm`) | Keeps the post spacing exactly the one used for the grid and targets |
| 2026-11-14 | Site bare-ground fraction = share of non-water Sentinel-2 pixels with annual NDVI below 0.2 | Common NDVI convention for bare rock, sand and soil (USGS remote sensing phenology guidance: 0.1 and below barren, 0.2 to 0.3 shrub and grass); the threshold is stored in the file |
| 2026-11-14 | Sentinel-2 snow observations are left out of site NDVI and reported as `snowObsShare` | Matches the approved rule that bare ground means exposed, ice-free ground |
| 2026-11-14 | Only Sentinel-2 scenes flagged `earthsearch:boa_offset_applied` are used (about 92% of scenes) | The other scenes may carry a different reflectance offset; mixing them would bias NDVI |
| 2026-11-14 | Up to 3 least-cloudy Sentinel-2 scenes per month, scene cloud cover under 80%, cloud masked per pixel | Tropical sites rarely have a clear scene; per-pixel masking over several scenes gives most pixels data in most months |
| 2026-11-14 | Site rock type uses Macrostrat regional maps only at large, medium or small scale, never its generalized world map | The world map was wrong at two Indonesian sites (sediment at a lava tube, volcanic at a limestone karst) |
| 2026-11-14 | Where no regional map exists, rock type is the volcano's major rock type from the Smithsonian GVP, labelled scale "volcano"; otherwise null | A verifiable database value; nothing is inferred for non-volcanic sites |
| 2026-11-14 | Site rock names map to a GLiM class code only through an exact-name table in `pipeline/sites.py`; anything else has code null | Avoids guessing a class for mixed or unusual units such as impact breccia |
| 2026-11-14 | Monthly site climate covers all 40 sites in analogs.json and takes the value of the POWER grid cell containing the site, no interpolation | "Never interpolate"; the file labels every field scale "grid" |
| 2026-11-14 | Monthly precipitation is stored as mm/month (source mm/day times days in month, February 28.25) | A monthly total is what a "best month" chart needs; the conversion is stated in the file |
| 2026-11-14 | Solar irradiance is POWER `ALLSKY_SFC_SW_DWN` in W/m2 (24 hour mean, horizontal surface, all sky), from the CERES SYN1deg 1 degree grid | It is the surface value the sandbox formula needs; W/m2 matches the Moon and Mars figures in DESIGN.md |
| 2026-11-14 | Extracts are 20 km squares in a local orthographic projection, each dataset at its native pixel size (30 m, 80 m, 463 m) | One ground scale for the split view without upsampling coarse data to look finer than it is |
| 2026-11-14 | Featured lava tube for the extracts is Gua Lawa | It is the only Indonesian tube whose own coordinates are published; the other two are centred on a village or a volcano |
| 2026-11-14 | Extracts are built for all seven targets, not only Gale | Ijen and Merapi are matched to Gale only; the split view may show any target and the extracts are small |
| 2026-11-14 | The Haworth LROC image is null (100% near-black); Shackleton's is kept with `darkShare` 0.86 | A black square is not an image; permanent shadow is recorded as a number instead |
| 2026-11-14 | Open water in site footprints comes from the Copernicus DEM water mask, not Sentinel-2's classification | The classification labelled 86% of the Timanfaya lava field as water |
| 2026-11-14 | Goa Pandan rock type "basalt" is taken from the abstract of Sirait et al. 2023; Maros-Pangkep rock type is null | Pandan's abstract was retrieved and states it; no retrievable source text was found for Maros-Pangkep |
| 2026-11-14 | earth.bin stores scaled integers (uint8, uint16, int16) with the same decimals as earth.json | Exact round trip with the JSON, checked on every build, and 8 times smaller |
| 2026-11-15 | The new sites (Tambora caldera, Batur lava fields, Dasht-e Lut, Salar de Uyuni, Tunupa) are defined in `pipeline/sites.py` (`EXTRA_SITES`), not added to `analogs.json`; `sites.json` marks them `inAnalogsJson: false` | `analogs.json` belongs to Session C; the app and scoring will not see these sites until Session C adds them |
| 2026-11-15 | Tambora footprint: 7.4 km square centred on 8.2438 S, 117.9918 E, marked provisional | Rim traced on Copernicus DEM GLO-30 as the highest point along 180 rays from the caldera floor: crest 3.1 to 4.2 km from its centre, 7.1 km N-S by 7.4 km E-W, crest 2272 to 2694 m. Smithsonian GVP (volcano 264040) says "6-km-wide, 1250-m-deep caldera"; the DEM crest-to-crest width is larger, so the DEM outline was used and the difference recorded |
| 2026-11-15 | Batur lava footprint: 4.0 km square centred on 8.2556 S, 115.3628 E, marked provisional | Bounding box of OpenStreetMap relation 19753621 (`natural=bare_rock`, two outer rings, 7.5 km2, 4.0 km N-S by 3.2 km E-W, version 3 of 2025-10-25), the only mapped outline of the bare lava found. GVP (volcano 264010) confirms historical basaltic flows on the caldera floor but has no outline. The outline was not drawn from Sentinel-2, so `bareFrac` is not circular |
| 2026-11-15 | Batur lava `bareFrac` is reported as measured (0.083), not adjusted | Only 8% of pixels have annual NDVI under 0.2: half the square is outside the polygon and dark lava with moss and grass reads above the threshold. The threshold is the same for every site |
| 2026-11-15 | "Salar de Uyuni with Tunupa volcano" is entered as two comparison sites, `salar-de-uyuni` and `tunupa-volcano`, 5 km each | Summit and salt surface are about 50 km apart at the published points; one small footprint cannot hold both |
| 2026-11-15 | Coordinates for Dasht-e Lut, Salar de Uyuni and Tunupa are Wikidata coordinate statements (Q767128, Q76122, Q849364); all three footprints are provisional | The UNESCO page for the Lut Desert could not be retrieved and Tunupa is not in the Smithsonian GVP databases. Wikidata gives no reference for them, so a team member should check |
| 2026-11-15 | Dallol footprint is 3 km on the GVP crater coordinates already in `analogs.json`; provisional | No outline of the hydrothermal field was found |
| 2026-11-15 | GVP "No Data (checked)" is stored as a null rock type; Dallol's rock type then comes from the regional map ("volcanic") | It is the database saying it has no value, not a rock name |
| 2026-11-15 | GVP rock type "Trachybasalt / Tephrite Basanite" (Tambora) maps to GLiM class 2, basic volcanic rocks | Trachybasalt and basanite are basic (low-silica) volcanic rocks by definition; the table still maps exact names only |
| 2026-11-15 | Salar de Uyuni keeps its measured values with a `caveat` field instead of being forced to "bare, flat" | The Copernicus DEM water mask classes 96% of the footprint as water and Sentinel-2 classes the salt as snow; overriding the masks for one site would be a hand edit |
| 2026-11-15 | `analogSource` is null for Salar de Uyuni and Tunupa; for Dasht-e Lut it is a conference abstract title | No paper calling them planetary analogs was retrieved in the time available; they are marked "known" on the team member's word |
| 2026-11-15 | Session C added `id-tambora-caldera` and `id-batur-lava-fields` to `analogs.json` with the same ids and coordinates; the pipeline now takes them from there and keeps only the coordinate source in `EXTRA_SITES` (supersedes the first 2026-11-15 row for these two sites) | One definition per site; the build fails if the two files ever disagree by more than 0.01 degrees |
| 2026-11-15 | Batur is paired with the target `moon-marius-hills` that Session C added to `targets.json` (14.091 N, 56.77 W, Wagner and Robinson 2014), not with a separate pipeline-only item | One item per place in the extracts index; the LROC Lunar Pit Atlas point (14.0917 N, 303.2299 E) is the same place within 20 m |
| 2026-11-15 | Lunar elevation away from the south pole comes from LOLA LDEM_512 (59 m), written on 60 m pixels | The polar 80 m grid stops at 80 S; LDEM_512 is the same instrument and the grid Session C measured the target's terrain on |
| 2026-11-15 | An Earth image whose 20 km window crosses a Sentinel-2 tile edge is a mosaic of the tiles of one day (Tambora: 2025-09-05, tiles 50LNR and 50LPR) | Same satellite pass, so there is no seam in time; a single tile covers only part of the window |
| 2026-11-15 | The Marius Hills LROC image is kept as delivered, although it is dark (mare basalt) | Stretching contrast is a display choice for the app, not a data step |
| 2026-11-15 | EMIT covers the sites, so mineralogy was added: 16 of 17 sites have at least one EMIT L2B mineral granule (Haughton, at 75 N, is outside the ISS orbit); 11 have a usable one | Checked through NASA CMR by point for every site in `sites.json` |
| 2026-11-15 | EMIT mineralogy is null for Kawah Ijen, Gua Lawa, Goa Pandan, Lanzarote Timanfaya and Salar de Uyuni although granules exist | In every granule tried (up to 6, least cloudy first) the footprint was cloud, cirrus or water in the L2A mask, had no retrieval in the product, or lay across the scene edge. Nothing was substituted |
| 2026-11-15 | EMIT values are one granule per site, the least cloudy that leaves at least half the footprint valid; dates are not merged | Keeps every number traceable to one named granule; a mosaic over dates would mix seasons |
| 2026-11-15 | EMIT pixels with the product's fill value count as "no retrieval", not as "no mineral found" | At Kawah Ijen the whole footprint is fill in the only granule; reading that as "no minerals" would be a false measurement |
| 2026-11-15 | EMIT library matches that are not minerals (dry vegetation, plastic) are listed as the product gives them, with a note | Removing them would hide that the Indonesian sites are mostly vegetation at 60 m |
| 2026-11-15 | Earth wind is POWER `WS10M` (10 m, annual mean); aerosol is POWER `AOD_55` (550 nm optical depth, all aerosol types) | The POWER climatology has no dust-only variable; total aerosol depth is stated as such rather than called dust |
| 2026-11-15 | Permafrost is the Obu et al. 2018 permafrost probability map (ESA GlobPermafrost, PANGAEA, CC-BY); cells south of 25 N and all of Antarctica are null | The map covers Northern Hemisphere land only; writing 0 outside it would be a guess, and the matching Antarctic map was not added for lack of time |
| 2026-11-15 | `windSpeed`, `aod` and `permafrostFrac` are extra keys (like `snowIceFrac`), not scoring factors | Changing the factor list or weights is Session C's decision and needs the team's approval |
| 2026-11-15 | The JAXA cross-check uses the JAXA Earth API open archive (GSMaP precipitation normals, GCOM-C SGLI NDVI 2025) instead of G-Portal downloads | G-Portal needs a registered account and SFTP; the Earth API serves the same JAXA products as open files, so the check is reproducible without credentials |
| 2026-11-15 | JAXA values are a check only (`data/jaxa_check.json`); no NASA value is replaced | Agreement at the 40 to 43 named sites: precipitation Pearson r 0.975, NDVI r 0.992 |
| 2026-11-15 | Four more known analogs are measured at site scale: Beacon Valley, Don Juan Pond, Craters of the Moon, Askja | More known sites at the same scale as the Indonesian candidates gives the validation a fairer comparison; two of them are Antarctic, where the 0.5 degree cells are mostly ice |
| 2026-11-15 | The computer slept for about 15 minutes at 13:20 while downloads ran; a keep-awake hold was requested for the session | Background downloads stall during sleep |
| 2026-11-15 | Moon grid is 2 degrees and Mars grid 1 degree | Both are about 60 km at the equator, the ground size of an Earth 0.5 degree cell and of the 55.6 km terrain window |
| 2026-11-15 | Moon and Mars cell terrain uses the target method (55.6 km square window centred on the cell centre, local orthographic projection), not a latitude-longitude cell | A latitude-longitude cell shrinks to a sliver at the poles, where the lunar targets are; windows overlap towards the poles instead |
| 2026-11-15 | Lunar grid terrain uses LOLA LDEM_64 (474 m posts) instead of resampling a finer grid to 463 m | 0.5 GB instead of 8 GB on a slow link; checked against the five lunar targets measured from finer data: slope within 3%, roughness within 5% |
| 2026-11-15 | Mars elevation for the grid is the USGS 463 m mosaic of the MOLA 128 pixel per degree MEGDR | Same data as the PDS tiles used for the targets, one file on a faster server; the three Mars targets agree within 6% in slope and 1% in roughness |
| 2026-11-15 | Mars temperature for the grid comes from Mars Climate Database maps (a model), not an orbiter product | It is the source Session C used for the Mars targets, so cells and targets are the same quantity; a TES or MCS climatology was not attempted in the time available. Badge "Literature" |
| 2026-11-15 | Mars `tempRange` uses 8 local times in 4 seasons (32 maps) instead of 24 x 24 | Each map takes about a minute on a shared research server; the result is stated as a lower bound |
| 2026-11-15 | Rock class tables: lunar mare units -> 2, dark mantling -> 12, highland/basin/plains units -> 4, crater units -> none; Mars volcanic units -> 2, Amazonian polar units -> 16, polar dunes -> 1, all other units -> none | Only units whose type states the material are classed; class 4 for highland crust follows the choice Session C made for the highland targets |
| 2026-11-15 | BLOCKED: SWIM Mars ice maps. swim.psi.edu returned HTTP 523 on every try on 2026-11-15, and no copy was found on Zenodo or USGS | Worked around with the Mars Odyssey GRS water map (`waterH2O`), labelled as not SWIM. Retry SWIM later |
| 2026-11-15 | Lunar ice signal is `psrFrac`, the share of a cell in permanent shadow; cells reaching below 65 degrees are null | The LOLA maps are complete only poleward of 65 degrees; shadow is where ice can survive, not a detection of ice |
| 2026-11-15 | Extracts now use LOLA 20 m at the lunar south pole, the HRSC-MOLA blended 200 m model on Mars, and a THEMIS daytime infrared image for Mars | Best open global products for a driveable terrain view; the Mars image is infrared, grey-scale, and labelled so |
| 2026-11-15 | Map unit names "Evaporite" and "Andesite and related volcanic" map to GLiM classes 14 and 10 | Each names the class itself (evaporites; andesite is the type intermediate volcanic rock). Names such as "volcanic", "sedimentary" or "basalt, latite" stay unmapped |
| 2026-11-15 | Lunar `tempMean` and `tempRange` stay null in 1,071 cells (the Apollo 11 and Apollo 17 cells among them) | Every one has a gap of 45 or 60 minutes in Diviner local-time coverage. Filling them would mean interpolating over a longer gap than the target method allows, or pooling neighbouring cells; both fill gaps, which the standing rule forbids. Session C asked for it and flags these cells instead. A team member can decide to relax the limit (MAX_GAP_STEPS in pipeline/moon_temperature.py) |
| 2026-11-15 | Maros-Pangkep rock type is now "limestone" (GLiM class 6), from the abstract of Maulany et al. 2019 (supersedes the 2026-11-14 null) | A Crossref search today returned an abstract that states it; the value is still literature, not a map unit |
| 2026-11-15 | EMIT minerals are searched in product version 2 and then version 1 (scenes version 2 lacks), up to 8 granules per site | Kawah Ijen had one version 2 granule with no retrieval but 18 version 1 granules |
| 2026-11-15 | EMIT mask bug fixed: every mask band whose name ends in "flag" now removes a pixel (cloud, cirrus, water, spacecraft, aggregate, SpecTf cloud). Earlier runs read only the older cloud flags, which are empty in newer masks | Kawah Ijen's footprint was cloud in the granule used, so its mineral matches were false. Corrected result: Kawah Ijen and Maros-Pangkep mineralogy dropped to null; Mauna Kea and Craters of the Moon moved to another granule; the other 15 sites are unchanged |
